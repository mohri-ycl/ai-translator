⚙️ 設定

取得 API Key：platform.openai.com/api-keys
✅ 已連線 📊 試算表 📁 資料夾
一次設定，之後全自動 🎉
  1. 開啟 script.google.com → 點「新增專案」
  2. 刪除預設程式碼，將下方提供的 google-apps-script.js 內容全部貼上
  3. 點上方「部署」→「新增部署」→ 類型選「網頁應用程式」
  4. 執行身分：我　誰可存取：所有人　→ 按「部署」
  5. 複製「網頁應用程式網址」，貼到上方欄位
完成後試算表和資料夾會自動建立在你的 Google Drive 裡
